### 项目概述
- 主题：学术研究与技术转移
- 技术栈：Vite 5.4 + React 18 + React Router 6 + react-markdown + remark-gfm
- 功能：文章列表、文章详情（Markdown渲染）、标签分类、关于页面、搜索

### 文件结构
- 源码目录：`C:\Users\psjjs\Desktop\个人网站\blog\`
- 运行目录：`C:\Users\psjjs\blog-temp\`（含 node_modules）
- 开发服务器：http://localhost:3000/

### 关键问题与解决
1. **npm install 失败**：沙箱内 npm 无法正常下载包（managed node v22 的 npm 10.9.7 静默失败）
   - 解决：使用系统 npm 11.16.0 + 国内镜像 `registry.npmmirror.com` + 自定义缓存目录
   - 命令：`npm install --registry https://registry.npmmirror.com --cache <local> --fetch-timeout 15000`
2. **node_modules 复制到中文路径失败**：无法从 blog-temp 复制到含中文的 blog 目录
   - 解决：直接在 blog-temp 运行开发服务器，源码也复制到该目录
3. **中文路径下的 rm -rf 被 trash 机制拦截**
